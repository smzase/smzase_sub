> 生活在秋田的高中生森田芽衣子，某一天竟被贵族学校「天宫女学院」选为特别插班生！<br><br>
> 怀着对憧憬的东京校园生活的期待与不安，芽衣子踏上了前往东京的旅程——<br><br>
> 然而，在那里等待着她的，竟然是一家名为「刺猬弹」的漫画咖啡屋！？<br><br>
